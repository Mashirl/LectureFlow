# LectureFlow 界面术语表（glossary.md）

SPEC-v2 P14.8.1 第 3 步：核心概念在各界面语言中的统一译法。所有译者与审校以此为准；`zh-CN.json` 是原始来源。

- **en 列已定稿**（由 en 母语者译者编写，随 `en.json` 精修一并确定；审校意见见 `reviews/en.md`）。
- **zh-TW、yue-Hant-HK、ru、hi 列已定稿**（各语言母语者译者与审校确认后，由 lead 合并；改动理由与更细的用法见 `reviews/{locale}.md` 末尾的“glossary 定稿”一节）。以后修改某一列，请同时更新对应的语言文件。
- 一个概念只用一种译法；同一个按钮或状态名在句子中被引用时（例如“点‘重试’”），必须与按钮本身的文字一致。
- 不翻译：讲座内容、术语表条目、模型生成的标题与简介、课程名与课程代码、文件名（SYLLABUS.md、stream.mp4、config.toml）、模型名、品牌名（LectureFlow、DeepSeek、Claude、Anthropic、OpenAI、NVIDIA、Intel、CUDA、ffmpeg、faster-whisper）以及示例编号（W02L1、W??、CSC1003 W02L1@12:34）。
- 语言名称一律用该语言自己的写法：简体中文、English、繁體中文（台灣）、粵語（香港）、Русский、हिन्दी。

## 6. en 的写作约定（供审校与其他语言参考）

- 国际化简明英语，美式拼写（**lead 裁决：统一写 canceled / Canceled**，不写 cancelled）；不用 please / simply / just，不用感叹号，不用习语（例如不写 top up、worth a look、leave it alone）。
- 按钮、菜单项以动词开头，sentence case：Start all drafts、Clean up glossary、Update out-of-date lectures。
- **lead 裁决：正文中引用按钮、选项、分区名时一律加弯引号 “ ”**，文字与界面完全一致：select “Retry”、choose “Use the current settings”、under “Roles”。让用户操作按钮时正文写 **select**，悬停提示（tooltip）中写 **Click to …**。
- 页面名首字母大写、不加引号：in Settings、Back to Dashboard。
- 错误信息先说发生了什么，再说可以怎么做，用两个短句而不是分号长句：The provider “X” has no API key. Add it in Settings, then select “Retry”. “refresh” 单独出现时写全：Refresh the page.
- 句末标点：完整的句子（错误信息、提示、toast、tooltip、说明文字）以句号结尾；标签、按钮、菜单项、状态短语（Invalid file name、Self-test passed）不加句号。
- `notes.*` 与 `warnings.*` 会被 `common.clause_sep`（“; ”）拼接，句末不加句号。
- 会被代入其他句子的片段（`{what}`、`{when}`、`{hint}`、`{error}` 等）要先看拼接后的整句：例如 `{when}` 可能带“tomorrow”，所以写 “Next peak: {when}” 而不是 “starts at {when}”；`common.class_hint.*` 以句号结尾，所以 `transcript.mark.tip` 写 “{name}: {hint} Click to see the change.”。
- 后端只传 `{count}`、不传 `n` 的计数，不能写成复数对象，要改写成不依赖单复数的句子（例：Lecture numbers will change (lectures affected: {count})）。
- 复数键用 `one` / `other`，计数参数必须叫 `{n}`（`t()` 按 `params.n` 选择形式）；不需要变化的形式也要两种都写。
- 日期、时间、数字、文件大小由代码按语言格式化，不要在文案中手写日期。
